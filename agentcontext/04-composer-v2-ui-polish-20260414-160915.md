# Composer V2 UI 打磨：发送按钮、比例调整、可拖拽高度

> 时间戳：2026-04-14 16:09  
> 基于 Composer V2（斜杠补全 + 图片输入）的 UI 迭代。

---

## 一、需求

### 1. 圆形发送按钮
- 删除工具栏右侧的 `/ for commands` 提示文字
- 替换为圆形发送按钮（类似 ChatGPT 的上箭头圆形按钮）
- 空内容时浅灰色，有内容后变深灰色
- 点击触发发送（等同 ⌘Enter）

### 2. 加号按钮放大
- `+` 按钮和发送按钮的视觉比例对齐
- 参考 ChatGPT/Claude 风格的工具栏图标大小

### 3. 可拖拽调整 Composer 高度
- 允许用户拖动 Composer 顶部边缘来改变大小
- 高度范围限制在合理区间
- 拖拽时有视觉反馈（光标变化）

## 二、技术方案

### 2.1 发送按钮
- SF Symbol `arrow.up.circle.fill`（28pt），无需自定义素材
- 颜色：`Color.primary.opacity(0.15)`（空）→ `Color.primary.opacity(0.5)`（有内容）
- `.disabled(composerState.text.isEmpty)` 防止空发送
- tooltip: "Send (⌘Enter)"

### 2.2 加号按钮
- 从 `font(.system(size: 14))` 调到 `font(.system(size: 18))`
- 加 `.frame(width: 28, height: 28)` 固定 hit area
- 和发送按钮的 28pt 圆形在视觉上等高

### 2.3 可拖拽高度
- 固定的 `minHeight`/`maxHeight` 改为 `@State private var composerHeight: CGFloat`
- `@GestureState private var dragOffset: CGFloat` 追踪拖拽中的偏移
- `effectiveHeight` 计算属性：`composerHeight - dragOffset`，clamp 在 `[60, 400]`
- 顶部加 drag handle：36pt 宽、3pt 高的圆角小条，`Color.primary.opacity(0.15)`
- `.onHover` 切换光标为 `NSCursor.resizeUpDown`
- 拖拽方向：上拖 = 增高（translation.height 为负，减去后变大）

## 三、文件变更

### 修改
```
Sources/Composer/ComposerInputView.swift
  - 删除 "/ for commands" 文字和相关 if 分支
  - 工具栏右侧新增发送按钮（arrow.up.circle.fill）
  - + 按钮 font size 14→18，加 28x28 frame
  - 静态 minHeight/maxHeight 替换为 @State composerHeight + @GestureState dragOffset
  - 新增 composerDragHandle 视图（drag handle + DragGesture）
  - .frame(minHeight:maxHeight:) 替换为 .frame(height: effectiveHeight)
  - 工具栏 .frame(height: 28) 改为 .padding(.vertical, 6)

Resources/Localizable.xcstrings
  - 删除 composer.slashHint（不再使用）
  - 新增 composer.send.help: "Send (⌘Enter)" / "送信 (⌘Enter)"
```

### 同时修复
```
Resources/slash-commands.json
  - 修复 6 条命令名的多余 "/" 前缀：/teleport→teleport, /theme→theme, etc.

Sources/Composer/SlashCommandRegistry.swift
  - loadBuiltinCommands() 加 safety strip：加载时自动去除 name 的 "/" 前缀
```

## 四、常量变化

| 属性 | 旧值 | 新值 |
|------|------|------|
| 文本区高度 | `minHeight: 80, maxHeight: 200`（固定） | `composerHeight: 120`（可拖拽，范围 60-400） |
| + 按钮 font size | 14 | 18 |
| + 按钮 frame | 无 | 28x28 |
| 发送按钮 | 不存在 | `arrow.up.circle.fill` 28pt |
| 工具栏高度 | `frame(height: 28)` | `padding(.vertical, 6)` |
| "/ for commands" | 显示 | 删除 |
